## 📬 Contact Form Integration

This website uses **Google Apps Script** for sending messages via Google Sheets.

To enable:
1. Go to **Google Sheets → Extensions → Apps Script**  
2. Paste the provided Google Script code  
3. Deploy it as a web app (set to "Anyone with the link")  
4. Replace the script URL inside `index.html`:
   ```js
   const scriptURL = 'https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec';
